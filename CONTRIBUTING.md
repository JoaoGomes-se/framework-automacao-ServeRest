# Como contribuir

1. Atualize sua branch `main` local antes de começar.
2. Crie uma branch própria para a tarefa, com um nome descritivo, por exemplo `joao/arquitetura`.
3. Faça alterações pequenas e mantenha o escopo da tarefa.
4. Antes de abrir o pull request, execute `npm test` e `npm run lint`.
5. Abra um pull request para `main` e solicite revisão de outro integrante da equipe.
6. Incorpore os comentários da revisão e aguarde a aprovação antes de integrar as mudanças.

Não faça commits diretamente na `main`.
